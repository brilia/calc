f is continuous, with selected values above.  Is there a time c, 1 < c < 7, such that f(c) = 0?  Justify.
We only know four points — but continuity lets us fill in everything between them.
The tool — Intermediate Value Theorem
If f is continuous on [a, b]
and f(a) and f(b) have opposite signs …
… then there is a c in (a, b) with f(c) = 0.
A continuous curve cannot jump over the x-axis — it must cross it.
Step 1 — Hunt for a sign change
✗ on (1, 2):  2 → 8  both positive
✗ on (2, 5):  8 → 2  both positive
✓ on (5, 7):  2 → −3  opposite signs!
a = 5,  b = 7,  f(5) = 2 > 0,  f(7) = −3 < 0
Only one interval straddles zero — that's where the theorem applies.
Step 2 — Picture it
Any continuous path from (5, 2) to (7, −3) must cross the x-axis.
Step 3 — Justify (three sentences)
1 f is continuous — given.
2 f(5) = 2 > 0 and f(7) = −3 < 0 — opposite signs at the endpoints of [5, 7].
3 By the IVT, there is a c in (5, 7) with f(c) = 0.
Continuity → opposite signs → conclusion. All three, every time.
The answer
Yes — by the IVT on (5, 7), there is a c with f(c) = 0.
sign change → IVT → a root must exist
