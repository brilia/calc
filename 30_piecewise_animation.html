The question
g(x) = { a tan−1(2x) + b,   x ≤ 12 e2x−1 − 1,   x > 12
g is continuous and differentiable at x = 12.  Find b.
(A) −π2 (B) −π4 (C) π4 (D) π2
The plan
two conditions, two unknowns.
continuity pins one equation — the pieces must meet.
differentiability pins the other — the slopes must match.
Solve them in order: differentiability gives a, then continuity gives b.
Step 1 — Continuity at x = 1/2
a tan−1(2 · 12) + b = e2·(1/2)−1 − 1
a tan−1(1) + b = e0 − 1 = 0
aπ4 + b = 0
tan⁻¹(1) = π/4, and e⁰ − 1 = 0 — so the pieces meet only if aπ/4 + b = 0.
Step 2 — Differentiability at x = 1/2
left:  2a1 + 4x2  →  at x = 12:  a
right:  2e2x−1  →  at x = 12:  2
slopes match:  a = 2
Trap: the leading a scales the arctan derivative — don't drop it.
Step 3 — Solve for b
aπ4 + b = 0  ⇒  b = −aπ4
with a = 2:  b = −2π4 = −π2
Substitute a = 2 into the continuity equation and simplify.
The answer
(A)  b = −π2
(A) −π2 (B) −π4 (C) π4 (D) π2
continuity → aπ/4 + b = 0;  differentiability → a = 2;  so b = −π/2.
