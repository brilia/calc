h(x) = 2 sin(x) − g(x).  Find h″(0).
Two derivatives to take, then one value to read from the table.
Step 1 — First derivative
h(x) = 2 sin(x) − g(x)
h′(x) = 2 cos(x) − g′(x)
Derivative of sin is cos; g differentiates to g′.
Step 2 — Second derivative
h′(x) = 2 cos(x) − g′(x)
h″(x) = −2 sin(x) − g″(x)
Derivative of cos is −sin — that's where the minus sign comes from.
Step 3 — Read g″(0) from the table
x −2013
g(x) −189−4
g′(x) 1053
g″(x) 24−67
g″(0) = 4
The x = 0 column is the one we need — read straight off the bottom row.
Step 4 — Evaluate at x = 0
h″(0) = −2 sin(0) − g″(0)
= 0 − 4 = −4
sin(0) = 0 kills the first term — only the table value survives.
The answer
h″(0) = −4
