The question
limx → −3 x2 − 9x2 − 4x − 21
First instinct: plug in −3. Let's see what happens.
Step 1 — Try direct substitution
numerator  (−3)2 − 9 = 0
denominator  (−3)2 − 4(−3) − 21 = 9 + 12 − 21 = 0
0/0  — indeterminate!
0/0 doesn't mean "no limit" — it means "not yet". Both parts vanish, so something shared may cancel.
Step 2 — Factor everything
numerator  x2 − 9 = (x − 3)(x + 3)   difference of squares
denominator  x2 − 4x − 21 = (x − 7)(x + 3)   −7 · 3 = −21,  −7 + 3 = −4 ✓
(x − 3)(x + 3)(x − 7)(x + 3)
There it is — the same purple factor on top and bottom.
Step 3 — Cancel (for x ≠ −3)
(x − 3)(x + 3)(x − 7)(x + 3) = x − 3x − 7
cancelling is legal: as x → −3, x is never equal to −3, so x + 3 ≠ 0.
The cancelled (x + 3) is exactly why direct substitution failed — it was hiding the 0/0.
Step 4 — Now substitute x = −3
limx → −3 x − 3x − 7 = −3 − 3−3 − 7 = −6−10
= 35   negatives divide out
No 0/0 this time — the simplified form is clean at x = −3.
The answer
limx → −3 x2 − 9x2 − 4x − 21 = 35
0/0 → factor → cancel → then substitute
